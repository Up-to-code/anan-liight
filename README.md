# Anan liight

Anan liight application source built with React.

[Source](https://github.com/Up-to-code/anan-liight) · [Issues](https://github.com/Up-to-code/anan-liight/issues) · [Project directory](https://github.com/qentrah/.github/blob/main/profile/PROJECTS.md)

## Technology

React, Vite, TypeScript.

## Get started

```sh
git clone https://github.com/Up-to-code/anan-liight.git
cd anan-liight
```

Requires Node.js and npm.

```sh
npm ci
npm run dev
```

## Available commands

| Command | Purpose |
| --- | --- |
| `npm run dev` | Development server |
| `npm run start` | Start the configured application |
| `npm run build` | Build the project |
| `npm run test` | Run the configured tests |
| `npm run typecheck` | Check types |
| `npm run lint` | Check lint rules |
